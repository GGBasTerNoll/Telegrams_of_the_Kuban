# Телеграммы по Кубани (ВЕБ приложение + приложение на Android)

Телеграммы по Кубани (ТПК) - свободный мессенджер для личного использования, современный дизайн, стабильные обновления и многое другое

## Как открыть ВЕБ приложение

1. Перейдите на главную страницу репозитория tpk на Github
2. Нажмите на синюю ссылку справа
3. Откроется главная страница мессенджера
4. Выберите в вашем браузере функцию "На экран домой"
5. Всё готово! ВЕБ версия установлена.

Для установки нативной версии под Android необходимо перейти в Releases и скачать apk файл оттуда и установить.

## Что уже есть

- Вход по email/паролю, регистрация, анонимный вход и создание профиля
- Чаты из Realtime Database (`chatsMeta`, `chats/.../messages`)
- Поиск людей по юзернейму
- Отправка текстовых сообщений (совместимо с вебом)
- Тёмная тема и выход
- Оформление
- Статусы
- Реакции, пересылка, редактирование, закрепление сообщений
- Звонки
- Каналы
